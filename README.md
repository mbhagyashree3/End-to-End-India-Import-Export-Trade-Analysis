# 📊 End-to-End India Import & Export Trade Analysis using MySQL, SQL Server & Power BI

## 📌 Project Overview

This project is an end-to-end Data Analytics solution that analyzes India's import and export trade data using **MySQL**, **SQL Server**, and **Power BI**. The project demonstrates the complete workflow from database creation and data transformation to interactive dashboard development for generating meaningful business insights.

The raw trade dataset was first imported into **MySQL**, where the database was designed and organized. The processed data was then transferred to **SQL Server** and connected to **Power BI** for data modeling and dashboard creation.

---

# 🎯 Objectives

- Design a structured relational database
- Clean and organize trade data using SQL
- Transfer processed data from MySQL to SQL Server
- Build an interactive Power BI dashboard
- Analyze import and export trade performance
- Generate business insights through data visualization

# 📂 Project Workflow

### Step 1 – Data Import
- Imported the raw India Import & Export dataset into MySQL.

### Step 2 – Database Design
- Created a structured relational database.
- Organized the data into normalized tables.

### Step 3 – Data Cleaning & Transformation
- Cleaned and validated the data using SQL.
- Removed inconsistencies and prepared the data for reporting.

### Step 4 – Data Migration
- Transferred the processed database from MySQL to SQL Server.

### Step 5 – Dashboard Development
- Connected SQL Server to Power BI.
- Built relationships between tables.
- Designed interactive dashboards.
